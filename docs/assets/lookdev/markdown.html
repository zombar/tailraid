The rename script

Run it from the folder it should touch; it never follows symlinks and asks before anything is overwritten.

for f in *.flac; do
  mv -i "$f" "$(printf '%02d' "$n") ${f#* - }"
  n=$((n + 1))
done

Keep the originals until the sums match. — a note to self after the 2023 mishap.
