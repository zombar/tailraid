tailraid pike

Sign in

This volume knows its people by a key on their own device, not by a password. On a device where you have a tailraid identity, run:

tailraid web login --node pike

It prints a link that opens here and signs this browser in for a week. The link is a one-time code minted by your key; it works once and for five minutes.

That link was already used, or is older than five minutes. Run the command again for a new one.

No identity yet? Ask an admin for an invite: tailraid user invite <name> on their side, tailraid user create <name> <code> on yours.
